# Angular i18n

Временный выбор локалей для инициализации: исходная `en-US`, дополнительные `ru` и `ua`.
Состав локалей можно изменить в `angular.json`, когда появятся требования к контенту.
Перевод пустой, поскольку интерфейс и демонстрационный контент не входят в эту задачу.

Помечать будущий текст атрибутом Angular `i18n`, строки TypeScript — `$localize`.
`npm run i18n:extract` создаёт исходный `messages.xlf`; перевод обновляется в `messages.ru.xlf`, `messages.ua.xlf`.
`npm run build` собирает все локали, а `npm run start:ru`, `npm run start:ua`запускает одну русскую/украинскую сборку.
Отсутствующие переводы приводят к ошибке сборки.

`LOCALE_ID` устанавливается в `app.config.ts` для выбранного режима Vite и используется API Layer.
Vite переводит скомпилированные `$localize`-сообщения через инструменты Angular
из XLIFF-каталога; русская сборка завершается ошибкой при отсутствии перевода.
Переключение языка между локализованными сборками будет отдельной задачей.
