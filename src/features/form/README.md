# Форма заявки

Самостоятельный Angular-компонент с адаптивным модальным окном. Имя необязательно;
способ связи и контакт обязательны. Для Telegram можно указать имя пользователя
или ссылку `https://t.me/`; для WhatsApp требуется номер телефона в международном
формате с префиксом `+`; для Email — адрес электронной почты. Проверяется формат
контакта, а не существование аккаунта.

Импортируйте `ApplicationForm` и `ApplicationData` из `@features/application-form`.
Для открытия окна добавляйте компонент в шаблон по условию. При событии `closed`
удаляйте его из шаблона; повторное создание компонента сбрасывает все поля.
Нативное диалоговое окно удерживает фокус внутри формы и поддерживает закрытие
клавишей Escape.

Способ связи выбирается через собственный компонент `Select` из `@shared/ui/select`,
без нативного `<select>`. Список поддерживает управление стрелками, Home и End,
выбор через Enter или пробел, поиск по буквам и закрытие при клике снаружи или
переходе по Tab. Первое нажатие Escape закрывает раскрытый список, следующее — форму.
Обязательная звёздочка, рамка, стрелка и прокрутка оформлены в стилях компонента.

Событие `submitted` передаёт `{ name, method, contact }` после успешной валидации
и блокирует форму на время ожидания ответа. Подключите обработчик этого события
к своему API, затем вызовите `complete()` при успехе или `fail(message?)` при ошибке.
Сам компонент не отправляет сетевые запросы. Сейчас корневой компонент приложения
сразу вызывает `complete()` для локального предпросмотра; замените этот обработчик
перед подключением реальной отправки заявок.

Логотип в формате SVG воссоздан по предоставленному скриншоту. Для точного
соответствия фирменному стилю замените `public/assets/icons/snake-logo.svg`
оригинальным файлом. До добавления оригинальных файлов шрифтов используются
системные шрифты.

Проверка валидации (Node.js 24+): `node tests/contact-validation.mjs`.
